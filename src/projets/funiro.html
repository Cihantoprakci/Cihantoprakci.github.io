Funiro

Un contrôle d'une matinée pour intégrer une landing mobilier haut de gamme sur WordPress + Elementor. C'était mon premier vrai contact avec ce duo. Sans le savoir, je préparais le terrain pour Nova-tech, qui allait arriver quelques mois plus tard avec un vrai client.

L'exercice

Une marque fictive de mobilier haut de gamme, à intégrer dans une matinée sur WordPress + Elementor. Trois catégories produit (Dining, Living, Bedroom), photos en pleine largeur, un design sobre qui valorise le produit plus que l'interface. Mon boulot : monter le site en builder visuel, ajouter du CSS perso pour ce que Elementor ne couvrait pas.

Pourquoi ce projet compte dans le portfolio

C'était mon premier exercice sur Elementor. À l'époque, je ne savais pas que quelques mois plus tard, le même stack me servirait pour Nova-tech, vrai client d'entreprise CVC en Suisse romande. Funiro a été la rampe de lancement WordPress : l'exercice scolaire qui m'a donné l'autonomie nécessaire pour livrer ensuite en prod.

Ce que j'en retiens

Elementor est un compromis : rapide à monter, contraignant dès qu'on veut quelque chose de précis. La compétence n'est pas de "savoir cliquer dans Elementor". C'est de savoir où il s'arrête, et d'ajouter le CSS qui complète. Cette leçon, je l'ai apprise sur Funiro, je l'ai appliquée sur Nova-tech.
